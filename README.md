# DevSpace — 3D Interactive Developer Portfolio

A modern, interactive developer portfolio built with HTML, CSS, and Vanilla JavaScript. Designed with a futuristic aesthetic, animated backgrounds, and interactive elements to create an engaging user experience.

## Features

- Interactive 3D-inspired interface
- Responsive design for mobile and desktop
- Animated background grid
- Modern typography
- Interactive UI components
- Smooth transitions and animations

## Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Purpose

Developed as part of my Level 1 internship task to practice frontend development, JavaScript interactivity, DOM manipulation, responsive design, and UI development.
